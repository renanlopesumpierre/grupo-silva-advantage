# Grupo Silva — Vantagem Operacional

Landing page executiva em HTML/CSS/JS, com estética editorial escura, acento verde-limão e módulos ativáveis.

## Abrir

Abra `index.html` diretamente no navegador. Não há dependências de build.

## Direção estratégica

A página posiciona o Grupo Silva como infraestrutura de receita: diagnóstico de entrada, transformação em 90 dias, operação recorrente e laboratório de expansão. A narrativa foi enriquecida com mecanismos traduzidos de referências americanas, sem copiar textos ou ativos:

- Alex Hormozi / Acquisition.com: valor percebido, oferta e redução de risco.
- HubSpot: customer flywheel, retenção e indicação como motor.
- Gong: revenue intelligence, coaching e forecast com evidência.
- Virgin / Richard Branson: experiência de marca aplicada à operação.
- Ogilvy: clareza, prova e criatividade a serviço da compreensão.

## Publicação

Site estático, sem dependências de build. Para abrir localmente, abra `index.html`. O deploy recomendado é GitHub Pages na branch `main`, com a raiz do repositório como fonte.

## Nota de uso

As comparações são hipóteses estratégicas para discussão executiva. Antes de transformar qualquer iniciativa em meta, validar ICP, margem, ciclo de vendas, retenção e capacidade real do Grupo Silva.
